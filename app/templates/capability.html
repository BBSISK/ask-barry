How this is worked out

Every night, each skill's searches run against the same index as the question box. For each section found, an AI judge answers one narrow question: which is the highest tier this section shows? It must quote the words that prove it, and code checks that the quote is really in the section, otherwise the section counts for nothing. A skill's tier is the highest tier any checked section shows. There are no scores or averages.

"First evidence" is when the earliest supporting file was first committed. Cards are drafted the same way, and an example appears only after {{ who }} has approved it. Everything comes from public project documentation, so "Not evidenced" means the docs don't show it, not that the skill is missing.
